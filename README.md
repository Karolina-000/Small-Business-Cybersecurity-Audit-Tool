Small Business Cybersecurity Audit Tool
მცირე ბიზნესის IT გარემოს საბაზისო კიბერუსაფრთხოების ავტომატური აუდიტის ხელსაწყო.

შესაძლებლობები
ქსელის სკანირება (Nmap): ღია პორტებისა და სერვისების აღმოჩენა
Windows Security ლოგების ანალიზი: წარუმატებელი შესვლები, ახალი ანგარიშები და სხვა საეჭვო მოვლენები
ფაილების მთლიანობის კონტროლი (SHA-256): არასანქცირებული ცვლილებების აღმოჩენა
ვებსაიტის შემოწმება: HTTPS, security headers, SSL სერტიფიკატის ვადა
რისკის შეფასება: Low/Medium/High დონეები და საერთო რისკის ქულა
HTML ანგარიში რეკომენდაციებით
სტრუქტურა
├── main.py                  # გამშვები ფაილი
├── config.py                # პარამეტრები
├── requirements.txt
├── modules/
│   ├── risk_assessment.py   # Finding მოდელი + რისკის დათვლა
│   ├── network_scanner.py   # Nmap სკანირება
│   ├── log_analyzer.py      # Windows Event Log ანალიზი
│   ├── file_integrity.py    # SHA-256 checksums
│   ├── website_checker.py   # ვებსაიტის შემოწმება
│   └── report_generator.py  # HTML ანგარიშის გენერაცია
└── reports/                 # გენერირებული ანგარიშები
ინსტალაცია
pip install -r requirements.txt
ქსელის სკანირებისთვის საჭიროა Nmap (nmap უნდა იყოს PATH-ში).

კონფიგურაცია
config.py-ში შეცვალეთ:

NETWORK_TARGETS: თქვენი ქსელის დიაპაზონი (მხოლოდ ავტორიზებული!)
FILE_INTEGRITY_TARGETS: კონტროლირებადი ფაილები/საქაღალდეები
WEBSITE_TARGETS: თქვენი საიტის URL(ები)
გაშვება
# baseline-ის შექმნა (ერთხელ, სანდო მდგომარეობაში)
python main.py --build-baseline

# სრული აუდიტი
python main.py

# მოდულების გამოტოვება
python main.py --skip-network --skip-logs

# ლოგების სადემონსტრაციო (ყალბი) მონაცემებით, მხოლოდ ტესტირებისთვის
python main.py --demo
ანგარიში ინახება reports/audit_report_<თარიღი>.html სახელით. გახსენით ბრაუზერში.

⚠️ ეთიკური და სამართლებრივი შენიშვნა
ხელსაწყო განკუთვნილია მხოლოდ საკუთარი ან წერილობით ავტორიზებული სისტემების შესამოწმებლად. არაავტორიზებული სკანირება შეიძლება იყოს კანონდარღვევა (საქართველოში კომპიუტერულ სისტემაში უნებართვო შეღწევა სისხლისსამართლებრივად დასჯადია).

შესაძლო გაფართოებები
CSV/JSON ექსპორტი
დაგეგმილი გაშვება (cron / Task Scheduler)
ისტორიის შენახვა და ტენდენციების გრაფიკი
Email შეტყობინება High-risk findings-ზე

Baseline-ის დაცვა (არასავალდებულო)
baseline_hashes.json-ის ხელით შეცვლის აღმოსაჩენად დააყენეთ გარემოს ცვლადი AUDIT_BASELINE_KEY (გრძელი საიდუმლო ფრაზა), მაგ. Windows-ზე:
setx AUDIT_BASELINE_KEY "ჩემი-გრძელი-საიდუმლო-ფრაზა"
მერე თავიდან გაუშვით python main.py --build-baseline. გასაღები არ შეინახოთ კოდში ან baseline-თან ერთად.

სრული შეცდომები იწერება audit.log-ში (პროექტის საქაღალდეში).
